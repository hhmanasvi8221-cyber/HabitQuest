# HabitQuest

A personal habit tracker built with React and Vite. Create and organize daily habits, record check-ins, review your weekly momentum, and celebrate streaks and achievements.

## Run locally

```sh
npm install
npm run dev
```

## Features

- Add, edit, and delete habits with a category, daily goal, icon, and accent color.
- Mark habits complete or incomplete and see daily progress update immediately.
- Review the last seven days of activity, current streak, and achievement badges.
- Keep habits, check-ins, and the selected color theme in browser local storage.
- Switch between dark and light themes; the dashboard adapts to mobile and desktop screens.

Run `npm run build` to create a production build and `npm run lint` to check the source.
